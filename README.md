# App Presupuesto 1.0 - WP Refrigeración

Aplicación web moderna y responsiva para la gestión integral de presupuestos de servicios de refrigeración y climatización.

## Características Principales

- **Gestión de Presupuestos:** Creación paso a paso de presupuestos oficiales con cálculo automático de subtotales, descuentos e impuestos.
- **Exportación a PDF en 1 Hoja:** Generación de presupuestos en formato A4 optimizado para impresión y archivo digital.
- **Compartir Nativo:** Envío directo del archivo PDF adjunto por WhatsApp utilizando la Web Share API (con fallback automático para descarga directa).
- **Gestión de Clientes e Historial:** Historial de presupuestos con opciones de edición, duplicación, filtrado y búsqueda rápida.
- **Catálogo de Precios y Plantillas:** Plantillas predefinidas de instalación, mantenimiento y materiales para confección rápida.

## Tecnologías

- **React 19 + Vite**
- **jsPDF + html2canvas**
- **Lucide Icons**
- **Vanilla CSS / Responsive Glassmorphism Design**

## Instalación y Ejecución Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
